## Feature: Contact Form Validation
**Added by:** Anuj Singh

**What it does:**  
A contact form that validates Name, Email, and Phone fields before submission.
Shows inline error messages for invalid inputs and a success message on valid submission.

**How to test:**
1. Open `index.html` in a browser
2. Click Submit without filling anything → should show error messages
3. Enter invalid email (e.g. `abc`) → should show "Enter a valid email"
4. Enter phone with letters or less than 10 digits → should show phone error
5. Fill all fields correctly → should show "Form submitted successfully!"
