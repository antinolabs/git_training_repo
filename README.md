## Feature Added: Total Tracker & Reset
I have enhanced the Row Counter with two major improvements:
1. **Total Sum Tracker**: Automatically calculates the sum of all "Saved" entries so the user knows the grand total.
2. **History Reset**: Added a reset button with a confirmation prompt to clear previous entries and start over.

## How to Test
1. Open `index.html` in your browser.
2. Click **INCREMENT** a few times and hit **SAVE**.
3. Observe that the "Total Rows" updates dynamically.
4. Click **RESET HISTORY** to clear the dashboard.
