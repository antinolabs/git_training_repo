## Features Added

### Reset Button Feature
**Author**: sweTa0204  
**Date**: January 15, 2026

#### What was added?
A **RESET button** has been added to the Row Counter application. This new feature provides users with the ability to clear all data and start fresh.

#### Functionality
- **Reset Button**: Clears the current count and resets the previous entries list
- **Button Location**: Positioned below the SAVE button on the UI
- **Button Color**: Red/Orange (#C73E1D) to distinguish it from other actions
- **JavaScript Function**: 
eset() - Resets the counter to 0, clears the count display, and resets the previous entries text

#### How to Test
1. Open index.html in your browser
2. Click the **INCREMENT** button several times to increase the counter
3. Click **SAVE** to save entries (optional)
4. Click the **RESET** button to clear the counter and all previous entries
5. Verify that:
   - The counter display returns to 0
   - The previous entries list shows "Previous entries: " (empty list)

#### Files Modified
- index.html: Added reset button UI element
- index.js: Added reset() function
- index.css: Added styling for #reset-btn (red/orange background)
