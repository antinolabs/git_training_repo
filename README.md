# What
- Allows users to decrease the current count by 1 using a DECREMENT button.
- Ensures the count never goes below zero.
# Why
This enhancement gives users better control over the counter, making it easier to correct mistakes without resetting or saving incorrect values.
#  How 
- A new decrement() function is implemented in JavaScript.
- The function checks whether the current count is greater than zero before decreasing it.
- The function is called using the onclick event attached to the DECREMENT button.
