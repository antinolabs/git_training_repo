## Feature Added
- Enhanced the existing counter to allow users to choose a custom increment value instead of incrementing only by one.

## How to Test
1. Open index.html in a browser
2. Enter a number in the "Increment by" input field
3. Click the INCREMENT button
4. Verify the counter increases by the chosen value
5. Click SAVE to store the entry and reset the counter
