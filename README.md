## Feature: Profile Card Component

### What was added
A reusable profile card UI component displaying a user avatar

### How to test it
1. Open `index.html` in your browser
2. Scroll to the Profile Card section
3. You should see a card with an avatar, name, role label, and a button
4. Hover over the button to verify the hover effect works
