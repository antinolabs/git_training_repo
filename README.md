## Feature: Random Animal Image Viewer

A simple UI component has been added that allows users to view random images of cats and dogs. This is in addition to the original row counter functionality.

### How to Test

1.  Open the `index.html` file in your web browser.
2.  You will see the original row counter and below it, a card with a random cat image loaded by default.
3.  Click the "Get Cat" button to fetch and display a new random cat image.
4.  Click the "Get Dog" button to fetch and display a new random dog image.
5.  The row counter should still function as before.
