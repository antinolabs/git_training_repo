# Row Counter Application

##  Author
**Name:** Dhruv Gupta  

---

##  Summary
This project is a simple and interactive Row Counter web application built using HTML, CSS, and JavaScript.  
It allows users to increment, decrement, reset, and save counter values with an easy-to-use interface.

---

##  Features

###  Implemented Functionality
- Increment counter value  
- Decrement counter value  
- Reset counter to zero  
- Refresh counter after saving  
- Save previous entries  
- Simple and clean UI

---

##  Technologies Used
- HTML  
- CSS  
- JavaScript
