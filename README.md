## Row Counter

A simple JavaScript-based row counter application built for Git training and collaborative development practice.

This project demonstrates basic frontend concepts such as DOM manipulation, state handling, and user feedback mechanisms.

---

## Features

- Increment a counter value
- Save counter values as history
- Display previously saved entries
- User feedback messages for actions:
  - Successful save confirmation
  - Informational message when there is nothing to save
  - Error message when maximum count limit is reached
- Maximum count limit to prevent invalid values
- Clean and responsive UI
