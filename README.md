### Description
I have upgraded the basic Row Counter into a different count name Tracker. Users can now:
- Assign a specific name to their counts (e.g., "Red").
- Save counts to a  list that remains even after refreshing the page.
- View a history of all saved counters.

### How to Test
1. Open `index.html` in your browser.
2. Enter a counter tracker name in the  input field.
3. Use the "INCREMENT" button to count rows.
4. Click "SAVE". The entry will appear in the "Previous entity" section below.
5. Refresh the page; observe that your previous entries are still visible thanks to LocalStorage.
6. There is a "RESET" Button were we can reset the counter as well as the name before pressing "SAVE"
